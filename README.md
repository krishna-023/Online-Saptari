 🌐 Online Saptari

An online web platform built with **Laravel & modern web technologies** to provide dynamic, scalable, and user-friendly features for users and administrators.  
This project aims to deliver efficient online services and information related to the Saptari region.

---

## 🚀 Features

✔ **User Registration & Authentication**  
✔ **Admin Dashboard**  
✔ **Dynamic Content Management**  
✔ **Responsive UI**  
✔ **Database-Driven Web Pages**  
✔ Optimized for performance and scalability  
✔ Easy installation with environment configuration  

> More features can be added based on specific project requirements.

## 📋 Installation

Follow the steps below to set up the project locally:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/krishna-023/Online-Saptari.git
   cd Online-Saptari
Install Composer Dependencies

composer install
Install NPM Dependencies

npm install
Environment Configuration

Duplicate .env.example

Rename to .env

Configure database credentials

DB_DATABASE=online_saptari
DB_USERNAME=root
DB_PASSWORD=
Generate App Key

php artisan key:generate
Run Migrations & Seeders

php artisan migrate --seed
Compile Frontend Assets

npm run dev
Run the Local Server

php artisan serve
Visit: http://localhost:8000
